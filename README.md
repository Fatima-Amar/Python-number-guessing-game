# Python-number-guessing-game <br>
Python Number Guessing Game. A simple beginner Python project using random numbers and loops.
<br>
<p> Python Number Guessing Game 
<br>
This is a simple Python console-based number guessing game.
The program generates a random number between 1 and 20, and the player tries to guess it.
The game provides feedback if the guess is too high or too low and counts the number of attempts.
Players can choose to play again after each round. </p>
<br>
<p>Concepts Used

while loops

if-elif-else conditions

User input & validation

Python random module
</p>

<p> ## How to Run

1. Make sure Python is installed
2. Run the file:

python python_game.py</p>
